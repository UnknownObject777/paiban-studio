# 一句话生成规范文档 — 使用指南（内部推广版）

> 适用版本：main ≥ `04072db`（2026-08-18）
> 一句话概括：在首页对 AI 说一句"帮我起草一份投标文件"，平台自动起草内容、套用公司规范格式、生成可直接交付的 Word 文档，全程本地、可回滚。

## 快速开始

```bash
npm install
npm run fetch:onlyoffice   # 首次：拉取预览 SDK（约 600MB，内网需镜像）
npm start
```

首次使用点右上角「模型设置」填入模型凭证（默认 DeepSeek；内网可填 OpenAI 兼容网关 baseUrl，凭证只存本机 `config.json`）。

## 三条主路径

### 1. 一键生成（landing 三个快捷按钮）

首页「一键生成」区：**生成投标文件 / 生成实验报告 / 生成外汇申报单**。
点击 → 示例指令填入输入框 → 把 ××× 改成实际项目名/主题 → 发送。
AI 起草 markdown 内容（缺失信息一律「×××」占位，不编造公司名与金额）→ 调 `doc_generate` 套用内置规则集 → 新文档自动打开、存版本 v1。

### 2. 自由对话生成

不开任何文档，直接在首页输入框说：

- "帮我起草一份智慧园区项目的投标文件"
- "写一份单摆测重力加速度的实验报告"
- "生成一份境外汇款申请书，收款方是香港公司"

生成后可继续对话精调："报价表加一行培训费""技术部分扩充到三级标题"（走 doc_edit 改已有文档）。

### 3. 按公司模板排版（公司格式落地路径）

1. 编辑态 →「模板」→「上传模板」：上传公司既有标书/公文范本 docx；
2. 系统自动反推排版规则集（标题/正文/表格/页边距等组件样式）；
3. 之后对任何文档说"按《XX 范本》的样式排"，或在模板抽屉选内置规则集「一键重排」。

### 4. 从模板填字段出稿（纯本地，无需模型凭证）

首页「从模板填字段出稿」→ 选模板 → 逐项填 `{{占位符}}`（没填的字段保留占位符，提示人工补）→「实例化为新文档」→ 自动打开预览。全程不经过 AI，离线可用；标书封面/投标函这类"换字段复用"的场景最快。seed 预置的「投标文件占位符模板（演示）」含 8 个占位符可直接体验。

## 内置规则集（手写资产，质量保底）

| 规则集 id | 适用 | 要点 |
|---|---|---|
| `gongwen-default` | 党政公文 | 仿宋正文、行距 28 磅、公文页边距 |
| `lab-report-default` | 实验报告 | 黑体标题、宋体小四 1.5 倍行距、图表题五号 |
| `bid-default` | 投标文件 | 大章另起页、报价表金额列自动右对齐、装订侧宽页边距 |
| `fx-form-default` | 外汇申报单（境外汇款申请书/涉外收入申报单） | 表单式高密度、字段表全边框、表头黑体加粗 |

标书章节结构（AI 起草时自动遵循）：封面信息 → 投标函 → 法定代表人身份证明及授权委托书 → 商务部分（资质/业绩）→ 技术部分（方案/实施/质保）→ 报价部分（一览表/分项报价表）→ 资格审查资料。

## 演示数据

```bash
node scripts/seed-demo-docs.mjs   # 需先 npm run build
```

向工作台数据目录预置三份生成示例（标书/实验报告/外汇单）+ 三份同名模板（模板幂等，重复执行不重复建）。

## 已知边界

- 只做 Word `.docx`；Excel/PPT 不在范围。
- 应用内实时预览（OnlyOffice 只读渲染）已可用；如遇异常，产物以「下载 docx」后在 Word/WPS 打开为准——生成文档已过 Word 实测（大纲导航、表格边框、金额列右对齐、分页均正确）。
- 每次修改自动存版本，改坏了在「版本」里一键回滚；原稿永不被改动（只处理副本）。

## 技术底座（给维护者）

- 生成链路：`src/docgen/`（markdown 解析 → 排版组件映射 → `applyEdits` seam 产出 docx）
- agent 工具：`doc_generate`（从零生成）/ `doc_edit`（改已有）/ `ruleset_read` / `template_read` / `version_store`
- 规则集：`templates/rulesets/<id>/{recognizers,styles}.json` 两文件，遍历校验测试自动覆盖新增规则集
- 全链路测试：mock LLM e2e（`test/e2e-mock-agent.test.ts`）覆盖"一句话 → doc_generate → 入库 → 事件流"，无需真实模型凭证
