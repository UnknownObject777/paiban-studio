# 主页美化提示词（paiban-studio · 首页/工作台主界面）

> 用途：当需要重构、美化或新增本程序主页（`public/index.html` + `public/styles.css`）界面时，把下面的提示词整段喂给前端 agent 执行。权威设计规范见 `docs/design/figma/DESIGN.md`，本提示词是它在三栏工作台场景下的具体化。

---

## 提示词正文

你是一名代表一线设计工程水准的前端设计师。请美化一个「AI 排版本地工作台」的桌面应用主页（Electron，三栏布局：左=模板库/工作文档，中=AI 对话流，右=实时预览/版本时间线）。技术栈为纯 HTML + CSS + 原生 JS，构建前必须通读 `docs/design/figma/DESIGN.md` 并严格执行以下约束。

### 硬性风格约束（Figma design system）

1. **界面 chrome 严格黑白**：只允许 `#000000` 与 `#ffffff`，辅以 `rgba(0,0,0,0.08)` 玻璃黑与 `rgba(255,255,255,0.16)` 玻璃白。禁止任何彩色强调色（不允许 `#4f8cff` 之类）。彩色只能出现在用户文档内容本身。
2. **几何**：所有按钮、tab、输入框一律 pill（`border-radius: 50px`）或正圆（`50%`）；卡片、对话框、预览容器用 8px；禁止直角按钮。
3. **字体层级靠字重微差**：可用字重 320 / 330 / 340 / 450 / 480 / 540 / 700，正文不超过 450，面板标题 540，主按钮 480，品牌与空态大标题 700。禁止使用 400/500/600。
4. **字距**：所有正文负字距（-0.1px 起，大标题 -0.6px 至 -0.96px）；等宽大写技术标签用正字距 0.54~0.6px；全局开启 `font-kerning: normal` 与 `font-feature-settings: "kern"`。
5. **focus 指示**：一律 `outline: 2px dashed #000`（呼应编辑器选择手柄），禁用实线 outline。
6. **阴影克制**：深度靠黑白背景对比与边框，不堆 box-shadow。
7. **间距**：8px 基数，刻度 4 / 8 / 12 / 16 / 24 / 32 / 48。

### 可用性目标（「足够用户可用」的验收标准）

- **零学习成本的首屏**：对话区空态即 onboarding——一句 display 级大标题说明产品能做什么 + 3~4 个 pill 形「示例指令」chip（如「标题改成黑体三号居中」「正文统一仿宋四号、行距 28 磅」），点击即填入输入框。
- **状态永远可见**：模型连接状态（检测中/就绪/未配置）用 pill 徽章区分（就绪=黑底白字，异常=白底黑框）；当前文档、版本数、下载按钮可用态一目了然。
- **空容器不空**：模板库、文档列表、版本时间线为空时显示虚线边框的引导文案（告诉用户下一步做什么），不留白。
- **主行动线唯一**：每个面板最多一个实心黑按钮（solid pill）作为主操作（「打开 docx」），其余为描边或玻璃按钮，避免注意力竞争。
- **安全感外显**：顶栏常驻「只处理副本 · 原稿不动 · 全程本地」的虚线 pill 提示。
- **窄屏可用**：<960px 时三栏收拢为单列，对话区保持最小 60vh。

### 落地规则

- 只改 `public/` 下的前端文件，不动 agent / docx 核心逻辑；如需接线（如示例 chip 填入输入框），用最小 vanilla JS 实现。
- 文案为中文、语气直接（「打开一篇排版混乱的 docx 开始」这种口语化引导优于「暂无数据」）。
- 完成后 `npm run typecheck` 无错，并启动应用截图自查：黑白二元是否被任何彩色破坏、pill 几何是否统一、空态是否有引导。
